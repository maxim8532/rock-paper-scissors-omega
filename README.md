# אבן, נייר ומספריים - התרגיל

השלימו את המחלקה `Game` כך שיתקבל הפלט הנדרש.

באפשרותכם להוסיף ולממש כל מחלקה או פונקציה נוספת שיעזרו לכם להגיע לפתרון.


### הנחיות
- אבן מנצחת מספריים, נייר מנצח אבן, מספריים מנצחים נייר - למי ששכח.
- המתודה `play()`: מקבלת את הבחירה של שחקן 1 ושל שחקן 2, ומחזירה מי ניצח (`rock beats scissors`) או `tie`.
- אם אחד השחקנים בחר צורה שלא קיימת במשחק, `play` מחזירה `invalid move: ` ואת הצורה (`invalid move: banana`), והניקוד לא משתנה.
- המשחק סופר ניצחונות. `score()` מחזירה את הניצחונות של שחקן 1, מקף, ואת הניצחונות של שחקן 2 (`2-1`).
- אסור שהתכנית תקרוס


סיימתם כש-`python main.py` מדפיס:

```text
rock beats scissors
scissors beats paper
tie
invalid move: banana
paper beats rock
Score: 2-1
```
